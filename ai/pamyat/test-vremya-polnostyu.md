Если Никита задаёт длительность теста (например, 26 часов) и говорит «если закончишь раньше — добавь тестов», тест должен занять всё время. Досрочный финал с отчётом — ошибка.

**Why:** 2026-10-01 тест Жреца закончил за ~16 ч из 26 и объявил итог. Никита спросил, почему тест получился вдвое короче, хотя он прямо просил дотестировать (тест мага по времени уложился верно). Причины: объём шагов задан числом боёв (n=40 на карту, Г 9,6 тыс. вместо ~25 тыс. по плану), а не временем; после перезапуска контейнера скорость выросла с ~1,25 до ~1,9 боя/с, и объём я не пересчитал; после контроля счёл работу законченной.

**How to apply:** план длинного теста строить по времени: у каждой фазы бюджет часов, объём (n, число итераций) пересчитывать по фактической скорости на каждом шаге. Финальный отчёт — только у срока. Если всё готово раньше, дальше идут дотесты из списка заранее: больше боёв на спорные карты, повторы на новых сидах, варианты по открытым вопросам, смелые идеи. См. [[dolgie-testy-ping]], [[dlinnyj-test-metodika]], [[zhrec-koncept]].
