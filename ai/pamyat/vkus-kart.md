2026-10-24 Никита разобрал банк идей мага (`heroes/mag/idei-kart.md`, раздел «Вкус Никиты») и сказал: «общие принципы те же», то есть правила ниже действуют для всех героев.

**Не нравится:**
- эффекты, которые надо отслеживать и которые не относятся к основной механике героя (окна «до конца раунда, когда союзник…», чтение намерений врага);
- эффекты, которые нарушают базовые правила игры и не являются частью механики героя (мгновенная скорость, несгорающая мана);
- общие приёмы без связи с образом героя (снять щит врага, «союзник выбирает», сравнять руку с союзником);
- дешёвый обход главной цены механики (списать долг без платы);
- скучные легендарки: из 9 вариантов мага Никита оставил 3 самых необычных.
- **Врождённая** (карта в руке с начала боя) пока не используется.

**Нравится:** карты, которые выворачивают свои зоны и механики героя (сыграть из сожжённых, сжечь ради эффекта сгоревшей карты, долг как ресурс с настоящей ценой); статус, который меняет поведение врага (не получает щит, бьёт сам себя); механика, у которой есть цена.

**Как работаем над картами героя:** Claude сам набирает банк идей в 3 раза больше числа карт (53 карты → ~159), без чисел; критерий — не меньше 80% идей заметно разные; Никита отмечает неуместные и понравившиеся номерами, Claude заменяет. Сначала согласуются билды и легендарки, потом карты.

**Why:** Никита ценит разнообразие и оригинальность внутри концепции героя, а не общие приёмы.
**How to apply:** проверять каждую идею карты любого героя по этим спискам до показа Никите.
