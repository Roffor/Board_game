# Сводка для нового чата

Длинный чат сжимается, и договорённости теряются. Сводка позволяет начать новый чат с того же места. Новый чат увидит только сводку и файлы проекта, поэтому она самодостаточна.

1. Сначала сохрани в файлы всё, что должно пережить чат: решения — в документы и журнал, правила — в память (`/zapomni`), состояние — в `STATUS.md`.
2. Затем выдай сводку одним блоком кода, чтобы её было удобно скопировать:

```
Продолжаем из прошлого чата. Сначала /nachalo.

Тема: <что делаем, 1–3 предложения словами Никиты>

Договорились:
- <решения и согласованные варианты, с причиной, если важна>
- <отклонённые варианты, к которым не возвращаемся>

Сделано:
- <что изменено и в каких файлах>

Осталось:
- <следующие шаги по порядку>

Ждёт решения Никиты:
- <вопросы>

Ключевые файлы:
- <путь> — <зачем>
```

Пустые разделы пропускай. Не вставляй содержимое файлов, новый чат прочитает их сам. Без истории обсуждения.
