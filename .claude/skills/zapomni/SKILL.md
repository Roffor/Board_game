# Запомнить

Формат и правила памяти — `pravila/05-fajly-pamyat-git.md §3`.

## Шаги

1. Определи, что это:
   - **решение по игре** → документ темы (раздел «Решения»), строка в `design/11-zhurnal-reshenij.md`, память `type: project`;
   - **правило работы** («делай отчёты по шагам», «не запускай без слова») → память `type: feedback` и строка в нужный файл `pravila/` (действующее правило), при важности — в `AGENTS.md`;
   - **порог баланса** → только с согласия Никиты: `playtest/00-soglashenie-po-balansu.md` и строка в его журнал §11;
   - **итог теста или этапа** → память `type: project` со ссылкой на отчёт.
2. Проверь `pamyat/MEMORY.md`: есть ли уже запись на эту тему. Есть — дополни её (дата, что изменилось). Устарела или неверна — исправь или удали.
3. Пиши коротко: факт с абсолютной датой, **Why:** (почему так решили, словами Никиты, если есть), **How to apply:** (когда применять), ссылки `[[...]]` на связанные записи и пути к файлам.
4. Обнови строку в `pamyat/MEMORY.md` (одна строка: суть + имя файла).
5. Никите — одна строка: «Записал: <суть> → <файлы>».

Не записывай то, что уже есть в файлах проекта (сошлись на файл), и то, что важно только для текущего разговора.
