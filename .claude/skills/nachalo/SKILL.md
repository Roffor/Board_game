# Начало сессии

Цель: за одну минуту чтения Никита понимает, где мы, и может сразу продолжить.

## Шаги

1. Прочитай, не пересказывая Никите:
   - свежий итог в `reports/obshchie/` (последний по номеру);
   - `ai/pamyat/MEMORY.md` и записи, которые относятся к текущим направлениям;
   - `ai/pravila/01-obshchenie.md` (если ещё не читал в этой беседе);
   - последние записи `ai/pravila/uroki.md` и свежие файлы памяти.
2. Посмотри, что изменилось с прошлого раза:
   - `git status` и `git log --oneline -15`;
   - `git pull`, если есть удалённый репозиторий: сервер мог запушить результаты прогона;
   - новые или обновлённые `reports/progony/*/itog.md` и `progress.md`.
3. Если Никита после команды написал тему — сосредоточься на ней и прочитай её файлы (`ai/pravila/` по таблице в `AGENTS.md` §5).

## Ответ Никите

Не больше 8–10 строк:
- **Где остановились** — 1–2 предложения.
- **Новое** — только если есть (например, прогон на сервере закончился: главная цифра и ссылка на `itog.md`).
- **Ждёт твоего решения** — самое важное открытое, коротко. Если вопросов много, не вываливай все: назови темы и предложи начать с самой влияющей.
- **Предлагаю сейчас** — один конкретный следующий шаг с причиной.

Не здоровайся длинно, не пересказывай правила и файлы.
