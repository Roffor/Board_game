# План теста для сервера

Сначала прочитай `pravila/03-balans-i-testy.md`, `pravila/04-stend-i-server.md`, формат плана в `stend/AGENTS.md` и пример `stend/plans/primer-dym.yaml`.

## Что согласовать с Никитой (группой вопросов, если не сказано)

- Цель теста одной фразой и **срок в часах** (срок — объём работы, не предел).
- Что агенту можно менять: какие числа и в каких границах, можно ли менять карты между колодой и банком, разрешены ли изменения механик (по умолчанию нет).
- Что считаем успехом.

Числа, формат фаз, объёмы волн решай сам.

## Как писать

1. **Файлы:** `stend/plans/ГГГГ-ММ-ДД-imya.yaml` и рядом `stend/plans/ГГГГ-ММ-ДД-imya.md`.
2. **md:** цель; гипотезы с числами («ожидаем: чистое Сжигание у босса 5,0–5,5 раунда»); критерии успеха; что агенту можно и нельзя; что делать при типичных сбоях; список дотестов.
3. **YAML:** `srok_chasov`, `seed0: sluchajno`, `tajmaut_boya_sek`, колоды героев, `pravki`, фазы с `dolya` (сумма 1). Фазы — `progon`, `test_bilda`, `podbor` (см. `stend/AGENTS.md`).
4. **Никаких «посмотри и реши».** Любое «если» — условие на число, либо сетка вариантов в порядке приоритета, либо `podbor` с `parametry` и границами.
5. **Дотесты** в конце плана: что гонять, если фазы закончились раньше (повторы на новых сидах для спорных карт, варианты по открытым вопросам, смелые идеи).
6. Границы чисел — внутри [С 5] и лимитов врагов [С 4.1].

## Проверка перед отдачей

1. `python run.py proverka` в `stend/`.
2. Копия плана с `srok_chasov: 0.05` и другим `nazvanie` → прогон локально (1–3 минуты). Все фазы проходят, отчёты пишутся, ошибок боёв нет. Копию и её `runs/` удали.
3. Перечитай план глазами слабого агента: есть ли место, где ему придётся решать самому? Перепиши в условие на число.
4. Большой план (больше 4 часов или с подбором чисел) отдай субагенту `kritik` (режим проверки файла): он ищет «посмотри и реши», объём в боях, нет дотестов, границы вне соглашения. Черновик плана может написать и `balansirovshchik`, но цель, срок и что агенту разрешено согласуй с Никитой сам.

## Отдача

1. Коммит «План: <имя>», `git push`.
2. Никите — коротко: цель, срок, гипотезы (1–3 строки), что агенту разрешено, и **готовый текст задачи для агента на сервере**:

```
git pull. Прочитай AGENTS.md. Запусти план plans/<файл>.yaml по правилам из AGENTS.md:
сначала python run.py proverka, потом кусками python run.py plans/<файл>.yaml --git --minut 9:
код 3 — пауза, проверь runs/<имя>/progress.md и запусти ту же команду снова; код 0 — план выполнен.
При зависании или падении перезапускай той же командой.
После каждой фазы: git pull --rebase и git push. Не заканчивай раньше срока. В конце запушь всё и напиши итог в zhurnal.md.
```

Запуск на сервере — по слову Никиты.
