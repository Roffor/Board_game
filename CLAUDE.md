## Только для Claude Code

- Команды проекта — скиллы из `.claude/skills/` (`/nachalo`, `/voprosy` и т.д., таблица в `AGENTS.md` §6). Субагенты `kritik`, `nastolshchik`, `balansirovshchik`, `igrok-novichok` — в `.claude/agents/` (кто когда нужен — `AGENTS.md` §6). Независимых субагентов запускай одновременно; долгого (балансировщик с тестом) можно в фоне.
- **Память проекта — `pamyat/`** (общая с Cursor). Автоматическую память Claude Code для решений по игре не используй: всё, что должно пережить сессию, записывай в `pamyat/`, `pravila/` и `STATUS.md` (`/zapomni`, `/itog`).
- **Прогоны стенда** запускай кусками `--minut 9` (присмотр раз в 10 минут получается сам) или в фоне с проверкой раз в 10 минут, не жди молча. Итог — сразу по завершении.
- Перед ответом на нетривиальный вопрос можно подумать дольше: качество важнее скорости.
- Если правило инструмента требует краткости, а краткость вредит пониманию, прав `AGENTS.md` §3.
