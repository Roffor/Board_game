## 3. Решил сам (числа и стенд)

- **Старт:** мага — «Полные руки» → «Пепельная завеса», «Сглаз» → «Гадание на углях», «Слабость» → «Нить порчи»; Паладина без замен. Большие отложенные щиты урезаны (Отложенный оберег 7 → 2, Обет утра 5 → 2).
- **Враги тренажёра** — пересобраны по решениям Никиты; итоговые намерения в `dungeons/trenazher/vragi/` (рядовые: удары 8 / 4 по обоим, щит 1–10; элита 8–9 / 4 по обоим; босс 9 / 4–5 по обоим, здоровье 62).
- **Карты банка:** сотни правок ±1 (полный список — `reports/progony/2026-10-26-B-podgonka/pravki.md`, у карт — `istoriya`); правка работы 5 карт (база «2 урона / 2 щита / Авангард»); цены Порчи-карт зафиксированы на 1.
- **Легендарки:** бонусы благословений у Пепельного трона, Двойной молитвы, Шипов → 0; предел жетонов Глубокого сглаза 6 → 3.
- **Стенд:** тревоги в отчёте круга; рамки врагов (щит, здоровье); рычаг — самое большое число карты; один рычаг на метрику за круг; шаг врага «по всем намерениям», когда ситуация далеко; правило побед по боям (рабочие пороги 99 / 99 / 97 / 85%); Вспышка фонаря на тренажёре выключена; ключ «ярость/усталость» (по умолчанию 0).

## 4. Мои ошибки за день (исправлены, правила в ai/pravila/uroki.md)

- Не видел большие отложенные щиты (рычаг брал первое число карты) — «щит у карт 1» было неправдой для старта.
- Правило побед «порог + 2%» давало 101% для рядовых — урон рядовым II не поднимался 3 круга.
- Враги правились только при общем перекосе — рядовые I стояли на 3,4 раунда.
- Тест встал на 30 минут: круг запущен без уведомления о завершении.
- Старт правился по 2 карты на героя — щит пары прыгнул с 5,5 до 8.
