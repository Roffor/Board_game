Никита 2026-09-28 предложил «полный тест»: база — обычный тест ([[obychnyj-test]]), но без каких-либо правок (даже автоматических), со сбором полной статистики; по итогам — комплексные предложения по механикам и выводы по всей игре.

Решено: запускать редко, сразу после крупных изменений механик, когда считается, что всё хорошо. Все пары героев. Проверка разных стилей игроков, по 3 полных забега на каждый стиль. Вердикт по каждой механике списком хорошо / нормально / плохо, с подробным разбором всего, что не «хорошо». Эксперименты с выключением механик пока не делаем.

Статус: только обсуждение; файл методики не писать и тест не запускать без явной просьбы. В симуляторе пока только Маг и Жрец.

Уточнено 2026-09-28: стили — осторожный, средний, жадный (различаются маршрутом, элитами, отдыхами; в бою у всех 25% ошибок). Отдельных логов забегов не собирать — один большой красивый отчёт. 200 автоматических забегов на пару для статистики остаются; статистику делить минимум на бои с непрокачанными и прокачанными колодами.
2026-09-28: методика оформлена в playtest/00-metodika-polnogo-testa.md (80 мелких боёв на пару, 54 забега по стилям, 1200 автоматических, отчёт одной страницей). Запускать только по явной просьбе.
