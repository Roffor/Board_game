Вопросы: cards/mag/15-metodika-dlinnogo-testa-voprosy.md. Ответы Никиты 2026-09-29:
- Сила считается в долях эталонных карт (стартовая +3 бюджета), полоса 70–130% эталона. Вес «раунды/здоровье» подбирается так, чтобы эталоны урона и щита были равны.
- Поражения — отдельная строка, в силу не входят. Ситуации весят поровну (цель — средний результат, а не имитация забега). Только одиночные бои, забеги — отдельный тест.
- Две точки: ранняя (ярус I) и поздняя. Врагов заморозить, стартовую колоду менять можно. База — случайные апгрейды (как «средний неидеальный забег»), оценка только по ним; разбивки по врагам не нужно; партнёр только Жрец.
- 60 боёв на ситуацию в базе, добор до 90–120 для спорных (уточнение 21:35); три состояния («точно в норме / точно вне / не ясно»); все сиды случайные (писать сид в результаты); 3 числа на карту вне полосы.
- Бот: отметка «не раскрывает» (<0,5 розыгрыша), логи, подсказки ценности будущего; замена — лучшая из 3 слабейших стартовых, следить за перекосом билдов по силе и лёгкости сбора.
- Тест пар, драфт 200 колод + 20 моих сборок; критерий сборок из п. 21 принят.
- Лимит **12 часов по времени** (в облаке), остановка только по времени; нашёл баланс — запомнить вариант и тестить смелые идеи. Между итерациями добавлять смелые идеи даже при сходящемся балансе.
- **Полная свобода концептов**, но сохранить «вариант 0» для отката.
- Отчётность: после итерации — мысли + краткая сводка; в конце — объёмный отчёт с рассуждениями.
- Смелые идеи: ориентиры MTG, Slay the Spire 1/2/настолка, Остров духов, Конец Эона + Balatro (другие игры Никита не хочет — не играл); перед стартом ресёрч ≤10 мин — по его слову.
- Старт — только по его слову.

**Why:** прошлая серия ([[test-bilda-parametry]]) показала, что полоса плавает с базой и шум сравним с полосой.
**How to apply:** при подготовке и запуске длинного теста мага; ответы записать в соглашение [С 8.7–8.10] ([[soglashenie-balans]]).
