# Дизайн-документы: «Двое во тьме» (рабочее название)

Набор документов по концепту настольной игры. Цель набора — чтобы человек или ИИ-ассистент, открывший его с чистого листа, восстановил весь контекст: что решено, почему, что отклонено и что ещё открыто. Состояние на **2026-09-28**.

## Что это за игра одной фразой

Кооперативный колодостроительный рогалик **строго на двух игроков** в духе Slay the Spire: у врагов заранее видны намерения, колода улучшается **заменой** карт, у каждого героя своя механика ресурса, а герои и приключения выпускаются как самостоятельные наборы.

## Цель проекта

Сделать **играбельный прототип** и показать его на выставке прототипов, которые проводят издатели. Автор — Никита. Концепт обсуждался в формате «Claude предлагает варианты, Никита решает».

## Метки статуса в документах

- **[решено]** — решение принял Никита. Не пересматривать без его инициативы.
- **[по умолчанию]** — допущение Claude, которое Никита не оспорил. Можно уточнить.
- **[открыто]** — вопрос не решён.

## Как Никита предпочитает работать

- Общение на русском.
- **Сначала механики, потом конкретные карты.** Никита не хочет обсуждать конкретные карты, пока концепции не зафиксированы, чтобы не уйти в бесконечные правки.
- Вопросы — **группами не больше 5**, по одной теме, с коротким контекстом, от самых влияющих к мелким. Варианты с пометкой рекомендации, отвечать можно коротко («1а 2б»).
- Для концептов хочет видеть варианты, плюсы и минусы, и насколько подход распространён в настольных играх.
- Принятые решения не переоткрывать; предлагать правки, только если нашлось реальное противоречие.
- Любит, когда у каждого героя есть выбор из трёх вариантов (например, три легендарки).
- Если механика «ломается» игроками в сторону силы, это допустимо и должно ощущаться как награда.

## Краткий словарь терминов

| Термин | Значение |
|---|---|
| Намерение | Что враг сделает в этом раунде; открыто заранее |
| Авангард | Жетон: одиночные атаки врага бьют того, кто его держит; получают только картами |
| Статус | Эффект героя на враге или союзнике; у каждого героя свой |
| «Даёт / Берёт» | Что герой даёт партнёру и от каких действий партнёра растёт его ресурс |
| Изгнание | Карта убирается до конца боя |
| Сдвиг намерения | Враг пропускает текущее намерение и переходит к следующему |
| Легендарка | Редкая карта героя, меняющая правило его ресурса; награда за элиту |
| Фонарь / масло / темнота / Вспышка | Механика первого приключения |
| След, Угроза, Ключ | Жетоны «памяти подземелья» |
| Этаж | Ряд карты пути из трёх комнат; всего 12 + босс |
